# Work Under Water

A simulator game made in Unity (C#).

![Gameplay](ссылка-на-gif.gif)

## Features
- Collect trash
- Get the highest point
- Hide from sharks

## Tech
- Unity [6000.4]
- C#

## Play
Download the latest build from [Releases](ссылка) or play on [itch.io](https://skridmop.itch.io/work-under-water2).

## Controls
- WASD - move
- SPACE - hide
